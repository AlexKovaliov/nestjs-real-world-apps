# NectMe — Case Study 2: Social Networking Platform

Backend for **NectMe**, a social networking platform built with NestJS, GraphQL and MongoDB.

## Setup

```bash
npm install
cp .env.example .env   # then fill in your values
npm run start:dev
```

The API runs on `http://localhost:3001` by default (case study 1 uses 3000).

## Tech stack

NestJS 12 · TypeScript 6 · GraphQL (Apollo Server 5) · MongoDB (Mongoose)
