# Real-World Applications, Deployment, and Security in NestJS

Practice projects from the Packt course **"Real-World Applications, Deployment, and Security in NestJS"**.

Each case study is an independent NestJS application with its own dependencies and database.

| # | Case study | Folder |
|---|------------|--------|
| 1 | E-commerce Platform | [`case-study-1-ecommerce`](./case-study-1-ecommerce) |
| 2 | Social Networking Platform | [`case-study-2-social-network`](./case-study-2-social-network) |

## Running a case study

```bash
cd case-study-1-ecommerce
npm install
npm run start:dev
```

Each project reads its configuration from its own `.env` file.

## Tech stack

NestJS · TypeScript · TypeORM · PostgreSQL · JWT
